🎙️ **DrovaVoice – deutsche Sprachausgabe für Drova** 🎙️

⚠️ **Alle Stimmen sind KI-generiert** (erstellt mit Fish Audio). Kein Mensch hat diese Zeilen eingesprochen.

Ich habe eine Mod gebaut, die Drova auf Deutsch vertont. Die Figuren sprechen ihre Dialoge, die Untertitel laufen ganz normal mit.

**Was drin ist**
• Über 14.000 vertonte Zeilen
• Jede benannte Figur hat ihre eigene, feste Stimme
• Zurufe in der Welt werden leiser, je weiter du weg bist
• Namenlose Figuren (Wachen, Arbeiter …) bekommen eine passende Stimme aus einem kleinen Pool
• Lautstärke und Entfernung im Optionsmenü einstellbar

**Was (noch) nicht**
• Deine eigenen Antwortoptionen bleiben stumm, wie im Original
• Briefe sind nicht vertont
• Nur für die deutsche Spielsprache

**Installation**
Du brauchst MelonLoader 0.7.3 und die Drova Modding API 0.5.4. Danach die Ordner `Mods` und `UserLibs` aus dem ZIP in deinen Spielordner kopieren. Die genaue Anleitung steht in der README im ZIP.
