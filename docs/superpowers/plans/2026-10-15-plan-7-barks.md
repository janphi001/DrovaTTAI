# Plan 7: Barks und Stimmenpool Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Welt-Kommentare (Barks) und Zeilen generischer Sprecher werden vertont: benannte Sprecher mit ihrer Besetzung, generische Figuren mit einer festen Stimme aus einem kleinen Pool, eigener Barks-Regler, Entfernungsabhängigkeit geprüft.

**Architecture:** Der Generator erweitert jede sprechbare Zeile eines generischen Sprechers beim Einlesen (`_selected`) um eine Zeile je Poolstimme (ID `Basis#vm1`, `#vw2` …); `Casting.voice_for` ordnet die Poolstimme über das Feld `Line.pool` zu. Der Index führt sie als Varianten. Die Mod liest per `FigureReader` Geschlecht und stabile ID der sprechenden Figur, wählt mit `PoolVoice.Pick` (FNV-1a) deterministisch eine Variante und spielt sie; fehlt die Figur, gilt die Wahl nach Zeilen-ID (Ansatz A). Barks liegen unter `bark/` und haben die Kategorie `Bark` mit eigenem Regler.

**Tech Stack:** Python 3 (pytest, Fish-Worker, ffmpeg), C# net6 (xUnit im Core, MelonLoader, Il2Cpp-Interop), Mono.Cecil (nur Wegwerfwerkzeug im Scratchpad).

**Spec:** `docs/superpowers/specs/2026-10-15-barks-design.md` (dazu `docs/audio-format.md`, `docs/playback.md`, `docs/HANDOFF.md`).

```csharp
using System;
using Il2CppDrova.DialogueNew;
using Il2CppInterop.Runtime;
using Il2CppNodeCanvas.DialogueTrees;
using UnityEngine;

namespace DrovaVoice.Playback
{
    internal sealed record FigureSnapshot(string? ActorName, string? BodyType, string? VoiceId, string? Guid, string? EntityKey, float? Distance);

    /// <summary>Liest die sprechende Figur einer Aussage. Jede einzelne Angabe ist unabhängig abgesichert; null = nicht lesbar.</summary>
    internal static class FigureReader
    {
        public static FigureSnapshot? Read(DS_StatementNode node)
        {
            try
            {
                var raw = node.finalActor;
                if (raw == null) return null;
                var dialogueActor = raw.TryCast<DS_DialogueActor>();
                if (dialogueActor == null) return new FigureSnapshot(Safe(() => raw.name), null, null, null, null, null);
                var actor = Try(() => dialogueActor.Actor);
                var body = actor == null ? null : Try(() => actor.GetActorGender());
                return new FigureSnapshot(
                    Safe(() => dialogueActor.name),
                    body == null ? null : Safe(() => body._bodyType),
                    body == null ? null : Safe(() => body._voiceId),
                    actor == null ? null : Safe(() => actor.GetGuidComponent()?.GuidString),
                    actor == null ? null : Safe(() => actor.GetEntityInfo()?.GetLocaKey()),
                    Distance(dialogueActor));
            }
            catch (Exception) { return null; }
        }

        private static float? Distance(DS_DialogueActor actor)
        {
            try
            {
                var cam = Camera.main;
                return cam == null ? null : Vector3.Distance(cam.transform.position, actor.transform.position);
            }
            catch (Exception) { return null; }
        }

        private static string? Safe(Func<object?> read) { try { return read()?.ToString(); } catch (Exception) { return null; } }
        private static T? Try<T>(Func<T> read) where T : class { try { return read(); } catch (Exception) { return null; } }
    }
}
```

- [ ] **Step 3: `PoolVoice` implementieren**

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;

namespace DrovaVoice.Core
{
    /// <summary>
    /// Wählt für generische Figuren eine Poolstimme (Variante vm1, vw2 …). Die Wahl hängt nur von Figurschlüssel
    /// (oder Zeilen-ID, wenn die Figur nicht lesbar ist) und der Variantenliste ab, damit sie über Sitzungen stabil ist.
    /// </summary>
    public static class PoolVoice
    {
        public static bool IsPoolTag(string? tag)
        {
            if (string.IsNullOrEmpty(tag) || tag!.Length < 3 || tag[0] != 'v' || (tag[1] != 'm' && tag[1] != 'w')) return false;
            for (int i = 2; i < tag.Length; i++) if (tag[i] < '0' || tag[i] > '9') return false;
            return true;
        }

        /// <summary>FNV-1a, 32 Bit, über die UTF-8-Bytes.</summary>
        public static uint Fnv1a(string text)
        {
            uint hash = 2166136261u;
            foreach (byte b in Encoding.UTF8.GetBytes(text ?? string.Empty)) { hash ^= b; hash *= 16777619u; }
            return hash;
        }

        public static string? Pick(IReadOnlyList<string> tags, char? gender, string? figureKey, string lineId)
        {
            var pool = tags.Where(IsPoolTag).OrderBy(t => t, StringComparer.Ordinal).ToList();
            if (pool.Count == 0) return null;
            if (gender is char g)
            {
                var matching = pool.Where(t => t[1] == g).ToList();
                if (matching.Count > 0) pool = matching;
            }
            string key = string.IsNullOrEmpty(figureKey) ? lineId : figureKey!;
            return pool[(int)(Fnv1a(key) % (uint)pool.Count)];
        }

        public static char? GenderFromBodyType(string? bodyType) => bodyType switch
        {
            "Strong" => 'm',
            "Petite" => 'w',
            _ => null,
        };
    }
}
```

public IReadOnlyList<string> PoolVariants(string? id) =>
    !string.IsNullOrEmpty(id) && _poolVariants.TryGetValue(id!, out var list) ? list : System.Array.Empty<string>();

private static Dictionary<string, List<string>> BuildPoolLookup(IEnumerable<string> ids)
{
    var map = new Dictionary<string, List<string>>(StringComparer.Ordinal);
    foreach (string id in ids)
    {
        int cut = id.LastIndexOf(LineIds.VariantSeparator);
        if (cut <= 0) continue;
        string tag = id.Substring(cut + 1);
        if (!PoolVoice.IsPoolTag(tag)) continue;
        string baseId = id.Substring(0, cut);
        if (!map.TryGetValue(baseId, out var list)) map[baseId] = list = new List<string>();
        list.Add(tag);
    }
    foreach (var list in map.Values) list.Sort(StringComparer.Ordinal);
    return map;
}

```python
from __future__ import annotations

from dataclasses import replace
from pathlib import Path
from typing import Mapping, Sequence

import yaml

from drova_voice.ids import VARIANT_SEP, with_variant
from drova_voice.lines import Line

GENDERS = ("m", "w")


def load_pools(path: Path, voices: Mapping[str, object]) -> dict[str, str]:
    """casting/pools.yaml -> {Tag: Stimmenschlüssel}; Tag = v<Geschlecht><Position ab 1>. Fehlt die Datei, ist der Pool leer."""
    path = Path(path)
    if not path.is_file():
        return {}
    raw = yaml.safe_load(path.read_text(encoding="utf-8")) or {}
    pools = raw.get("pools") if isinstance(raw, dict) else None
    if not isinstance(pools, dict):
        raise ValueError(f"{path}: 'pools:' mit den Listen m und w fehlt")
    result: dict[str, str] = {}
    for gender, keys in pools.items():
        if str(gender) not in GENDERS:
            raise ValueError(f"{path}: Unbekanntes Geschlecht '{gender}' (erlaubt: m, w)")
        for number, key in enumerate(keys or [], start=1):
            voice = str(key).lower()
            if voice not in voices:
                raise ValueError(f"{path}: Unbekannte Stimme '{voice}' im Pool '{gender}' (Schlüssel aus casting/fish_voices.yaml)")
            result[f"v{gender}{number}"] = voice
    return result


def expand_pool_lines(lines: Sequence[Line], pools: Mapping[str, str]) -> list[Line]:
    """Ersetzt jede sprechbare Zeile eines generischen Sprechers durch eine Zeile je Poolstimme (`<ID>#v<g><n>`).
    Benannte, übersprungene und schon variantenhaltige Zeilen bleiben unverändert."""
    if not pools:
        return list(lines)
    out: list[Line] = []
    for line in lines:
        if not line.generic or line.skip or line.pool or VARIANT_SEP in line.id:
            out.append(line)
            continue
        for tag in sorted(pools):
            out.append(replace(line, id=with_variant(line.id, tag), pool=tag))
    return out
```
